# Valorant Mobile

React Native app bootstrapped with Expo and configured to run on web first.

## Scripts

```bash
npm run web
```

## Structure

- `src/root` - application entry component.
- `src/screens` - screen-level UI.
- `src/components` - reusable UI components.
- `src/styles` - shared styling constants.
- `assets/images` - bundled image assets.
- `assets/fonts` - local font files.
- `assets/icons` - icon source files.

## Fonts

- `Valorant` is bundled from `assets/fonts/Valorant.ttf`.
- Body/UI sans uses DIN Pro from `assets/fonts/DIN Pro/` (`DINPro-Regular`, `DINPro-Medium`, `DINPro-Bold` are loaded in `src/styles/fonts.ts`).
